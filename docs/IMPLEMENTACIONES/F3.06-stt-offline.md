# F3.06 — Transcripción STT on-device

**Fecha:** 2026-10-12  
**Estado:** implementación terminada; validación de español real **parcial/bloqueada** por falta de soporte del locale en el AVD.  
**Prerrequisitos comprobados:** F3.03 contrato, F3.04 permiso contextual y F3.05 `VoiceCaptureSessionController` presentes.

## Implementación

`AndroidOnDeviceSpeechToTextEngine` implementa el contrato `SpeechToTextEngine` y recibe un adaptador Android pequeño para poder probar el ciclo sin micrófono. Solo acepta tags de español. Comprueba `RECORD_AUDIO`, y desde API 31 comprueba `SpeechRecognizer.isOnDeviceRecognitionAvailable()` antes de crear el motor mediante `SpeechRecognizer.createOnDeviceSpeechRecognizer()`. No llama a `createSpeechRecognizer()` ni aplica fallback de nube. En API 24–30 responde `EngineUnavailable` sin crear un reconocedor.

En API 33 o posterior consulta `checkRecognitionSupport()` y examina únicamente los idiomas on-device instalados, soportados y pendientes. Un locale instalado permite empezar; uno anunciado pero no instalado/pendiente se informa como `OfflineModelMissing`; idioma no soportado, servicio no disponible y permiso denegado son errores separados. No consulta idiomas online, no solicita descargas y no guarda audio. En API 31–32 empieza solo con la factory on-device y deja que el servicio devuelva errores tipados si el idioma o modelo no está disponible.

El adaptador transforma `RecognitionListener` en resultados parciales, finales y errores F3.03. `finish()` llama `stopListening()` y conserva la sesión para recibir el final; `cancel()` descarta el borrador. La sesión se serializa en `Dispatchers.Main.immediate`, donde Android exige operar el `SpeechRecognizer`; el callback de soporte usa el executor principal. Al terminar se quita el listener y se llama `destroy()`. La identidad de sesión descarta callbacks tardíos, y cada callback revalida el permiso. `VoiceCaptureSessionController` sigue siendo quien coordina inicio/parada/cancelación y notifica una revocación observada por su propietario. El resultado permanece en `SpeechToTextState.Result`; no se conecta a UI ni a Room y no se guarda automáticamente.

Se añadió la consulta de visibilidad del servicio `android.speech.RecognitionService` al manifiesto, necesaria para consultar servicios bajo la visibilidad de paquetes de Android 11+; no se añadió permiso nuevo ni dependencia. F3.04 sigue siendo el único origen del permiso de micrófono y la UI de voz continúa fuera de alcance (F3.08).

## Validación

- `assembleDebug` — correcto.
- `testDebugUnitTest` — **57 pruebas, 0 fallos**. Las 12 pruebas nuevas verifican API 24–30, permiso, disponibilidad y carrera al crear, resultado de idioma/modelo, rechazo de idiomas no españoles, estados parcial/final, stop, cancelación, callbacks tardíos, doble sesión, revocación, integración con F3.05, errores y liberación.
- `connectedDebugAndroidTest` — **24 pruebas, 0 fallos** en Pixel 8 AVD, API 35. La sonda incluida no fuerza permisos: en esta suite informó `not-run-permission-not-granted` y no abrió el micrófono.
- Intento real separado con modo avión activo y permiso temporalmente concedido en el AVD Pixel 8 API 35: el servicio on-device respondió `ERROR_LANGUAGE_NOT_SUPPORTED` para `es-PE`. Por tanto, no llegó a `startListening()`, no capturó voz y no produjo transcripción. **Transcripción de audio español offline real: no verificada.** El AVD anuncia la función de micrófono, pero no se probó una frase hablada ni se validó el hardware acústico. Modo avión quedó apagado y Wi‑Fi reconectado después de la prueba.
- No hubo Samsung físico ni prueba API 24–30; no se afirma soporte en esos dispositivos. No se descargaron modelos.

## Límites y handoff

El código está preparado para usar el motor local cuando el dispositivo proporcione servicio y modelo español compatibles, pero la puerta de salida de F3.06 permanece abierta hasta transcribir una frase sintética con red desconectada y micrófono disponible. Repetir esa validación en un AVD con locale español on-device instalado y en Samsung físico; registrar solo estados y métricas sin texto privado. Handoff sugerido: F3.07 — normalización del borrador, manteniendo explícita esta validación pendiente. No se avanzó a F3.07.
