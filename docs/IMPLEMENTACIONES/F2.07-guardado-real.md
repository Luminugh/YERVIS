# F2.07 — Guardado real desde Capturar

## Alcance e integración

`YezviApp` crea el `CaptureViewModel` asociado a la Activity con un `viewModelFactory`. El host entrega al ViewModel un `RoomMemoryRepository` sobre `YezviDatabaseFactory.getInstance(applicationContext)`. `MemoryScreen` sigue recibiendo únicamente `DemoMemoryRepository`; F2.08 queda fuera de este cambio.

La revisión del borrador ahora incluye Guardar. Al entrar por primera vez en Revisar, la pantalla crea un `CaptureInput` con el texto sin normalizar, origen `TEXT`, epoch UTC en milisegundos y zona de `TimeZone.getDefault()`. Si se cierra la revisión sin editar el borrador y se vuelve a abrir, reutiliza el mismo input; el ViewModel asigna un UUID al primer intento y lo conserva ante reintentos. Room y los mapeos existentes copian esos valores y el ID, sin cambios al esquema v1.

## Estados, errores y navegación

- `Idle`: muestra la vista previa y habilita Guardar.
- `Saving`: muestra el progreso y bloquea edición, limpieza, cierre y cambios de pestaña para evitar perder o duplicar el intento en curso.
- `Saved`: aparece solo cuando `MemoryRepository.save` retorna después del insert SQLite. Se confirma y se limpia el borrador; Listo cierra la revisión.
- `Failed`: muestra un mensaje genérico sin texto privado ni detalles SQLite. El borrador y `CaptureInput` permanecen; Reintentar llama `retry()` con el mismo ID. Cerrar la revisión también conserva el borrador.

Atrás con revisión abierta cierra primero el diálogo; Atrás con borrador pendiente abre la confirmación de descarte. Cambiar de pestaña con borrador pendiente conserva la confirmación existente. Descartar limpia el borrador y su contexto temporal; guardar una nota no navega automáticamente.

Inserta una fila con el ID que usará la captura para provocar una colisión real, comprueba que la UI informa el error y que la fila previa no se sobrescribe, conserva el texto editable, elimina la semilla y reintenta. Comprueba un único ID generado, los metadatos originales, el estado `SAVED`, limpieza tras éxito, ausencia de la nota real en Memoria demo y lectura del mismo registro después de cerrar/reabrir Room.
