# F1.09 — Línea temporal de Memoria

## Objetivo
Reemplazar el placeholder «Memoria» por una línea temporal que agrupe entradas por fecha local, usando los contratos F1.01 y los datos sintéticos F1.03.

## Archivos afectados
- `app/src/main/java/com/yezvi/assistant/ui/screens/MemoryScreen.kt` (nuevo): pantalla completa con `LazyColumn`, encabezados pegajosos, tarjetas y estados vacío/demo.
- `app/src/main/java/com/yezvi/assistant/ui/screens/PlaceholderScreens.kt` (modificado): se eliminó `MemoryScreen` placeholder; `SettingsScreen` permanece.
- `app/src/main/res/values/strings.xml` (modificado): cadenas de la línea temporal.
- `docs/ESTADO.md` (modificado): registro de entrega.

## Decisiones
- Agrupación por clave `yyyy-MM-dd` calculada con la zona horaria de cada entrada (`timezoneId`), usando `java.util.TimeZone` y `SimpleDateFormat` (sin dependencias nuevas ni desugaring).
- Orden cronológico descendente: días más recientes primero; dentro de un día, entradas más recientes primero.
- Encabezados «pegajosos» (`stickyHeader`) para que la fecha permanezca visible al desplazar.
- Tarjetas con color `surfaceContainerLow`, insignia de origen (`Texto`/`Voz`) y hora local en color primario; vista previa truncada a dos líneas.
- Banner `tertiaryContainer` visible: «Datos de demostración · aún no se guardan entradas reales».
- Estado vacío implementado pero no accesible con los fixtures actuales; se activaría automáticamente si `DemoMemoryRepository.getEntries()` devuelve una lista vacía.
- Sin navegación a detalle: F1.10 manejará la pantalla de entrada individual.
- Sin Room, IA, voz ni persistencia real.

## Verificación
- `./gradlew.bat assembleDebug` → BUILD SUCCESSFUL.
- `./gradlew.bat testDebugUnitTest` → BUILD SUCCESSFUL (12 tests).
- Emulador Pixel 8 API 35:
  - Pestaña Memoria muestra agrupación por día: Domingo 11, Sábado 10, Viernes 9.
  - Orden descendente verificado (10:15 antes que 08:05 dentro del 11).
  - Navegación Hoy → Memoria → Capturar → Hoy funciona.
  - Etiqueta de datos de demostración visible en la parte superior.

## Handoff
