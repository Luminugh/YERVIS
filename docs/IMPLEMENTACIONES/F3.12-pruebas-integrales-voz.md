La fuente de AGP **9.4.1 instalada en caché** explica el riesgo concreto, sin reproducir una desinstalación:

- `com/android/build/gradle/options/BooleanOption.kt:93`: `android.injected.androidTest.leaveApksInstalledAfterRun` tiene valor predeterminado `false`.

Esto es coherente con la desaparición observada en F3.11; no se dispone de una traza histórica que atribuya cada operación de aquella sesión. Se añade `android.injected.androidTest.leaveApksInstalledAfterRun=true` a `gradle.properties`. No se ha validado el comportamiento conectado modificado exponiendo datos del usuario: **no se ejecutó connectedDebugAndroidTest**.

La validación de esta fase usa `scripts/Invoke-F312VoiceTests.ps1`, mediante `adb shell am instrument -w -r` y AndroidJUnitRunner directo. Sin Orchestrator, runner Gradle conectado, reinstalación del APK principal ni operaciones de borrado. Solo se reemplaza el APK separado de pruebas. El script exige paquete existente, SHA-256 del APK instalado idéntico al compilado, identidad UID/firstInstallTime y ausencia de micrófono activo antes de comenzar. Si no coinciden, se detiene; no intenta reparar ni reinstalar la aplicación.

## Aceptación audible pendiente: intervención humana

**TTS audible offline: NO validado en esta ejecución.** El S21 FE expone una voz española que el adaptador clasifica como local; READY y retorno satisfactorio no demuestran reproducción.

Se preparó `ManualLocalTtsAcceptanceTest`, fuera del grupo automático y protegido por argumento `manualOfflineTts=true`. Exige modo avión, Wi-Fi/datos apagados; crea una base temporal UUID, opt-in OFF y controles explícitos. El usuario activa la confirmación y pulsa Guardar; CaptureViewModel guarda una nota sintética en esa base y solo entonces solicita «Recuerdo guardado». La persona debe pulsar si lo oyó o no. Se verifica escritura y veredicto humano, y se cierra/elimina únicamente la base temporal propia. No se graba audio.

**Detención actual:** ADB es inalámbrico; apagar Wi-Fi perdería el enlace. El usuario debe conectar USB con depuración autorizada y estar disponible para escuchar. Después se registrará conectividad inicial, se verificará conexión USB estable, se desactivará/verificará la red antes de la prueba y se restaurará al terminar, incluso ante fallo. No se ha modificado conectividad en esta ejecución. No se iniciará síntesis hasta esa participación; no se escribe en la base normal.

Tras confirmar USB y disponibilidad, ejecutar únicamente el método manual por AndroidJUnitRunner directo con `-e manualOfflineTts true`, preservando el mismo procedimiento de identidad/huella antes/después. Registrar motor/voz, red efectiva, veredicto y quién verificó audibilidad; no declarar éxito si solo consta una devolución de API. Falta también inspección visual humana de ese arnés.
