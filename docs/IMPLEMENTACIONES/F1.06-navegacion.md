# F1.06 — Navegación principal

**Fecha:** 2026-10-11 · **Agente:** OpenCode · **Ticket:** F1.06.

## Contexto
`TodayScreen` (F1.07) funcionaba a pantalla completa. Faltaba la estructura de navegación entre Hoy, Memoria, Capturar y Ajustes.

## Objetivo
Navegación funcional de 4 destinos con barra inferior, conservando `TodayScreen` y aplicando el sistema visual F1.05.

## Implementación
- **Dependencia:** Navigation Compose `2.10.2` (última estable verificada en Maven Google; compatible con el BOM actual).
- **Destinos:** `Destination` sealed class con `today`, `memory`, `capture`, `settings`.
- **Host:** `YezviApp` con `NavHost` y `rememberNavController`; destino inicial Hoy.
- **Bottom bar:** `YezviBottomBar` custom con 4 textos (sin iconos para evitar otra dependencia). Se integra como `bottomBar` del Scaffold de cada pantalla, minimizando cambios en `TodayScreen`.
- **Navegación entre tabs:** `popUpTo(Hoy) { saveState = true }`, `launchSingleTop = true`, `restoreState = true`.
- **FAB de Hoy:** conectado a `onCaptureClick` para navegar a Captura.
- **Pantallas pendientes:** placeholders claros con `tertiaryContainer` y texto "Pantalla de X".

## Archivos
- Nuevos: `ui/navigation/{YezviDestinations,YezviBottomBar,YezviApp}.kt`; `ui/screens/PlaceholderScreens.kt`.
- Modificados: `ui/today/TodayScreen.kt` (parámetro `bottomBar`); `MainActivity.kt` (muestra `YezviApp`); `res/values/strings.xml`; `gradle/libs.versions.toml`; `app/build.gradle.kts`.
- Sin cambios en contratos, Room, Gradle/AGP, Java ni `TodayScreen` visual.

## Pruebas
- `.\gradlew.bat assembleDebug testDebugUnitTest` → BUILD SUCCESSFUL.
- Emulador Pixel 8 API35: instalado y abierto.
- Secuencia probada con `uiautomator` + `input tap`:
  1. Hoy → Memoria (placeholder Memoria).
  2. Memoria → Ajustes (placeholder Ajustes).
  3. Ajustes → Hoy.
  4. FAB de Hoy → Capturar (placeholder Capturar).
  5. Botón Atrás del sistema → vuelve a Hoy.
  6. Segundo Atrás → sale de la app; sin crash en logcat.

## Riesgos / rollback
- Riesgo bajo: archivos nuevos y cambios mínimos en `TodayScreen`/`MainActivity`.
- Rollback: eliminar dependencia Navigation Compose y archivos de navegación; revertir `MainActivity`, `TodayScreen` y `strings.xml`.

## Handoff
- `TodayScreen` sigue siendo la vista de Hoy; la bottom bar la consume sin alterar su diseño.
- F1.08 (captura real) reemplazará el placeholder de Captura.
- F1.09 (timeline) reemplazará el placeholder de Memoria.
- F1.11 puede añadir animaciones de transición entre destinos.

## Ajuste de nombres y foco — 2026-10-14

Los rótulos visibles actuales son **Inicio**, **Recuerdos** y **Captura** (Ajustes permanece). El destino Captura no solicita foco ni abre el teclado al entrar desde la barra; la persona decide tocar el editor. El FAB de Inicio también navega a Captura en reposo, sin abrir el teclado.

La regresión instrumentada `YezviAppNavigationTest.mainNavigationTabsSwitchScreens` comprueba ambas entradas (barra inferior y FAB) y que el editor siga desenfocado en el S21 FE/API 35.
