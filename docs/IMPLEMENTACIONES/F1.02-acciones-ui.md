# F1.02 — Contratos de acciones UI

**Fecha:** 2026-10-11  
**Estado:** implementado y verificado

## Contrato

`MemoryUiCallbacks` expone tres solicitudes hacia la capa de presentación o el host de la app:

- `onCaptureRequested(CaptureInput)`: enviar una captura confirmada, reutilizando el contrato F1.01.
- `onNavigateTo(AppDestination)`: solicitar una de las pantallas iniciales `TODAY`, `MEMORY`, `CAPTURE` o `SETTINGS`.
- `onMemoryEntrySelected(String)`: seleccionar un registro mediante `MemoryEntry.id` estable.

Los callbacks expresan intención; no guardan datos ni realizan navegación. La selección transmite solo el ID para que el consumidor resuelva el registro. El estado de captura sigue siendo `CaptureStatus` de F1.01; no se añade otro estado.

## Decisiones y límites

- Se agrupan los tres callbacks relacionados en `MemoryUiCallbacks`; cada callback conserva una firma simple y tipada.
- No se crea una jerarquía sellada de eventos: no hay reducer ni despacho central que justifique eventos adicionales.
- `AppDestination` define nombres de destino, no una implementación de rutas ni una dependencia de Navigation Compose.
- `TodayScreen.kt`, `MainActivity.kt` y `DemoTodayItem` no se modifican. No se implementan ViewModels, Room, IA ni navegación.
