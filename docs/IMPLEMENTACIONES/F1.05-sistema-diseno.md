# F1.05 — Sistema de diseño «Memoria tranquila»

**Fecha:** 2026-10-11 · **Agente:** OpenCode · **Ticket:** F1.05 · Aplica la investigación F1.04.

## Implementación
1. **Color:** `dynamicColor = true` por defecto (Material You, Android 12+/One UI). Fallback estático con semilla teal `#00696B` (tonos 10–90) y acento ámbar para avisos de honestidad (`tertiaryContainer`). Roles: `secondaryContainer` = distintivos de tipo; `error` solo fallos.
2. **Claro/oscuro:** dos `ColorScheme` con pares on/container de alto contraste (≥4.5:1 verificado por construcción: tonos 10/20 sobre 80/90 y viceversa).
3. **Tokens:** `ui/theme/Tokens.kt` — `Spacing` (4/8/12/16/24 dp), `YezviShapes` (4/8/16/24/32 dp) y `Motion` (`StateChangeMillis = 200`, `ExpandCollapseMillis = 300`).
4. **Tipografía:** `Type.kt` sin fuentes custom; jerarquía F1.04 (`headlineSmall` fecha, `titleLarge` barra, `titleMedium` secciones, `bodyLarge` ítems, `bodyMedium` metadatos, `labelMedium/Large` distintivos y horas).
5. **Theme.kt:** cablea `colorScheme + typography + shapes`; conserva lógica dynamic color existente.

## Accesibilidad y movimiento
- Contraste por roles on/container; estados con texto, no solo color (heredado de F1.07).
- Sin fuentes fijas en dp: todo en `sp`, compatible con fontScale.
- `Motion` centraliza duraciones; el respeto a «reducir animaciones» se aplicará donde se usen animaciones (F1.11) leyendo la escala del sistema.
