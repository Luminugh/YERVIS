# F1.07 — Inicio «Hoy»

**Fecha:** 2026-10-11 · **Agente:** OpenCode · **Ticket:** F1.07 de `agentes/ROADMAP_MAESTRO.md`.

> Nota: `docs/IMPLEMENTACIONES/PLANTILLA.md` (referida por el roadmap) aún no existe; este documento sigue la estructura pedida en el roadmap.

## Contexto
El proyecto solo tenía la pantalla de plantilla `Greeting`. No existían navegación (F1.06), contratos de dominio (F1.01) ni persistencia (F2). Se ejecutó F1.07 de forma aislada para desbloquear la vista inicial con datos sintéticos.

## Objetivo
- Dashboard «Hoy» legible, con jerarquía del día: fecha, resumen, pendientes próximos y recientes.
- Datos **demo inequívocos**: banner visible que declara que no se guarda nada.

## No-objetivos
- Persistencia, contratos de dominio, Room, IA, voz, navegación entre pantallas, captura real.

## Diseño
- `Scaffold` (Material 3) con `TopAppBar` (título «Hoy» + fecha en español) y `ExtendedFloatingActionButton` «Capturar» (posición `End`, cerca del pulgar).
- `LazyColumn` con `contentPadding` que respeta los insets del Scaffold; secciones «Pendientes próximos» y «Recientes».
- Tarjetas con `Card` / `surfaceContainerLow`; cada ítem muestra un distintivo de tipo (Tarea/Evento/Idea) con **texto**, no solo color (regla UX).
- Estado vacío manejado; `@Preview` para datos demo y estado vacío.
- Fecha con `SimpleDateFormat(..., Locale.forLanguageTag("es-ES"))` para no depender de `java.time` (minSdk 24).

## Archivos / contratos
- Nuevo `ui/today/TodayScreen.kt` (composables `internal`).
- Modelo `DemoTodayItem`/`DemoItemKind`: **provisional, `internal`, solo UI**. No es contrato de dominio ni colisiona con `MemoryEntry` de F1.01.
- `strings.xml`: cadenas de interfaz en recursos.
- `MainActivity.kt`: muestra `TodayScreen`; `onCaptureClick` es no-op.

## Dependencias y versiones
Sin dependencias nuevas. Se usó Material 3 del BOM ya presente (`2026.02.01`). No se requirió `material-icons` (el FAB usa texto).

## Datos y privacidad
Datos 100% sintéticos en el código. Sin red, sin permisos nuevos, sin datos personales.

## Pruebas y resultados
- `.\gradlew.bat assembleDebug` → BUILD SUCCESSFUL.
- `.\gradlew.bat testDebugUnitTest` → BUILD SUCCESSFUL.
- Instalado/abierto en `emulator-5554` (Pixel 8 API35); el volcado de UI (uiautomator) confirma banner, resumen «3 pendientes · 2 recientes», secciones, ítems y FAB. Sin crash en logcat.
- Captura guardada en el equipo, pero **no pudo revisarse visualmente** por este agente (sin entrada de imagen); validación basada en jerarquía de UI.

## Riesgos / rollback
- Bajo riesgo: archivos nuevos + `MainActivity` (archivo compartido, dueño único este ticket).
- Rollback: eliminar `ui/today/TodayScreen.kt`, revertir `MainActivity.kt` y las cadenas de `strings.xml`.

## Decisión vinculada
No se abre ADR: no hay decisión duradera de arquitectura. La elección de un modelo demo `internal` en UI es temporal y será reemplazada por el contrato de F1.01 y la persistencia de F2.
