# F1.08 — Captura de texto

**Fecha:** 2026-10-12 · **Agente:** OpenCode · **Ticket:** F1.08.

## Contexto
`CaptureScreen` era un placeholder. No existían contratos de dominio (F1.01 pendiente) ni persistencia (F2). Se implementa la interfaz de captura textual con estados honestos.

## Objetivo
Pantalla de escritura natural, cómoda y accesible, con borrador temporal y revisión, sin simular persistencia real.

## Implementación
- **Nuevo `ui/screens/CaptureScreen.kt`:**
  - `OutlinedTextField` multilínea (`minLines = 6`, `maxLines = Int.MAX_VALUE`), foco automático (`FocusRequester`) y teclado visible al entrar.
  - Borrador en `rememberSaveable` (sobrevive rotación/proceso) pero **no en disco**.
  - Etiqueta "Borrador", placeholder "Escribe lo que quieres recordar..." y texto de apoyo: "Este borrador aún no se guarda en el dispositivo."
  - Barra de acciones inferior con "Limpiar" y "Revisar" (deshabilitados si no hay texto).
  - Diálogo "Revisar borrador" que muestra el texto y metadatos construidos con `CaptureInput` de F1.01 (origen TEXT, instante y zona horaria), advirtiendo que aún no se guarda.
  - Diálogo "¿Descartar borrador?" al pulsar Atrás con texto escrito; también intercepta cambios de pestaña inferior con borrador no vacío.
  - `BackHandler` de androidx.activity.compose para controlar el retroceso del sistema.
- **Teclado:** `Modifier.imePadding()` aplicado a la `Column` del `bottomBar` para mantener la barra de acciones y navegación visibles sobre el teclado (con `windowSoftInputMode="adjustResize"`).
- **Placeholder eliminado:** `CaptureScreen` se quitó de `PlaceholderScreens.kt`.
- **Cadenas:** añadidas en `res/values/strings.xml`.

## Archivos
