# F1.01 — Contratos básicos de memoria

**Fecha:** 2026-10-11  
**Estado:** implementado y verificado

## Alcance

Define modelos Kotlin puros para la entrada de captura, el registro de memoria y el estado de captura. No conecta la UI, persistencia, Room, voz, IA ni navegación. `DemoTodayItem` de F1.07 permanece en la capa de UI y no se migra en este ticket.

## Contratos

- `CaptureInput` contiene `rawText`, `sourceType`, `capturedAtEpochMillis` y `timezoneId` antes de crear el registro.
- `MemoryEntry` contiene esos datos, un `id` estable y `status`.
- `CaptureSourceType` acepta `TEXT` y `VOICE`. `VOICE` solo describe el origen del texto; no representa grabación ni reconocimiento implementado.
- `CaptureStatus` acepta `IDLE`, `SAVING`, `SAVED` y `FAILED`. `SAVED` debe usarse solo cuando el guardado local haya terminado realmente.
- `rawText` no se recorta ni normaliza. Ambos constructores rechazan texto en blanco; también se rechaza un ID o `timezoneId` en blanco.

## Decisiones

- `capturedAtEpochMillis` es un instante UTC en milisegundos desde Unix epoch. `timezoneId` conserva el identificador de zona IANA para interpretar y presentar la hora local; el contrato solo exige que no esté en blanco.
- `Long` evita depender de `java.time` con `minSdk 24` y sin desugaring configurado. No se añadió ninguna dependencia.
- El ID se asigna al crear un `MemoryEntry`; `CaptureInput` no representa todavía un registro persistido y no tiene ID propio. El generador y formato del ID quedan en la capa que crea el registro.
- Los modelos no importan Android ni Compose.

## Verificación

- `.\gradlew.bat assembleDebug` — `BUILD SUCCESSFUL`.
- `.\gradlew.bat testDebugUnitTest` — `BUILD SUCCESSFUL`; cinco pruebas de contratos y una prueba existente, sin fallos.
- Gradle necesitó el JBR de Android Studio. `JAVA_HOME` se estableció solo en el proceso de cada comando; no se cambió la configuración global.
