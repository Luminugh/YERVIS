# F1.04 — Investigación visual One UI / Material 3

**Fecha:** 2026-10-11 · **Agente:** OpenCode · **Ticket:** F1.04 · Sin cambios de código.
**Fuentes oficiales (2):** Samsung One UI Overview (developer.samsung.com/one-ui) y Material 3 AndroidX (Context7, androidx.compose.material3). m3.material.io y developer.android.com no cargaron (JS/timeout).

## 1. Identidad visual propuesta (única)
«Memoria tranquila»: superficies planas con elevación tonal (sin sombras duras), mucho aire y el **día como protagonista**. Diferenciador: honestidad de estado visible (demo / sugerencia / confirmado) con **texto + forma**, nunca solo color.
- **Color:** Material You dinámico por defecto en Android 12+/One UI (la app se adapta al fondo del usuario). Esquema estático de respaldo con semilla **teal serena (~#00696B)**; roles fijos: `tertiaryContainer` = avisos de honestidad (demo/sugerencia), `secondaryContainer` = distintivos de tipo, `error` solo para fallos reales. Tarjetas sobre `surfaceContainerLow/High`; fondo = `surface`.
- **Tipografía:** sistema/Roboto. Fecha del día en `headlineSmall`; títulos de sección `titleMedium` SemiBold; títulos de ítem `bodyLarge`; metadatos `bodyMedium` + `onSurfaceVariant`; distintivos `labelMedium`. Sin fuentes custom (peso y coherencia One UI).
- **Formas:** esquinas grandes y suaves (cards ~16–24 dp), lenguaje One UI; `Shapes` centralizado en F1.05.

## 2. Usabilidad a una mano (principio One UI «interactuar natural»)
- Zona superior = lectura (scroll); zona inferior 40% = interacción: FAB de captura, guardar/confirmar abajo.
- Objetivos táctiles ≥48 dp; márgenes laterales 16–24 dp; separación entre tarjetas 8–12 dp.
- Navegación futura (F1.06) en barra inferior con ≤4 destinos; nada crítico arriba.

## 3. Inicio, captura y timeline
- **Inicio:** cabecera de fecha grande colapsable (patrón `LargeTopAppBar` de M3 / toolbar colapsable One UI); resumen de una línea; máx. 2 secciones; estado vacío con una sola acción.
- **Captura:** hoja inferior o pantalla con foco automático en el campo, teclado visible y botón Guardar al alcance del pulgar; estado (guardando/guardado/error) junto al botón, no como toast lejano.
- **Timeline:** cabeceras de día *sticky* como clave de grupo; tarjeta = distintivo de tipo + hora + texto; detalle expandible; abrir haciendo scroll a hoy.

## 4. Animación funcional y accesibilidad
- Movimiento con significado y 200–300 ms: `AnimatedVisibility`/`expandVertically` para detalles y estados; FAB se oculta al bajar (estado derivado del scroll) y reaparece arriba.
- Sin bucles infinitos ni efectos permanentes. Respetar «reducir animaciones» del sistema (escala de animación 0) y futura preferencia de app.
- Accesibilidad: contraste ≥4.5:1; orden de foco y lectura de arriba a abajo; `mergeDescendants` en tarjetas para TalkBack; `contentDescription` en acciones sin texto; soportar fontScale hasta 200% sin cortes; estados nunca solo por color.

## 5. Mejoras puntuales a «Hoy» (F1.07) — para aplicar después, no ahora
1. Sustituir `TopAppBar` por `LargeTopAppBar` con fecha colapsable.
2. Cabeceras de sección *sticky* (`stickyHeader`).
3. Tarjetas: `semantics { mergeDescendants = true }` para lectura TalkBack en un nodo.
4. Ritmo vertical: 16 dp entre secciones, 8 dp entre tarjetas.
5. Mantener banner demo hasta F2 (honestidad), estilizado con `tertiaryContainer` ya correcto.
6. FAB con icono + texto cuando se apruebe la dependencia de iconos (F1.05/F1.06).

## 6. Recomendaciones para F1.05 (tokens)
- Crear `ui/theme/Tokens.kt`: espaciados (4/8/12/16/24 dp), radios (8/16/24 dp) y `Typography` con los estilos del punto 1.
- Aliases semánticos: `statusNotice = tertiaryContainer`, `typeBadge = secondaryContainer`; documentar uso.
- Color: `dynamicColor` activable + esquema teal de respaldo claro/oscuro con contraste verificado.
- Previews de galería: claro, oscuro y fontScale 200% como prueba de aceptación.
- No añadir dependencias; todo con el BOM actual.
